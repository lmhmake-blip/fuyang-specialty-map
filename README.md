# 阜阳特产地图 · 演示原型

面向**上海阜阳商会 / 同乡社群**的阜阳特产精选小程序原型。第一版只做「可信精选 + 礼盒 + 团购」，不做开放式多商家平台。

## 怎么打开

```bash
# 方式一：直接双击 index.html（最简单）
open index.html

# 方式二：本地服务器（推荐，手机可同局域网访问）
cd ~/Claude/阜阳特产小程序 && python3 -m http.server 8899
# 浏览器打开 http://localhost:8899
```

手机上看：Mac 和手机连同一 WiFi，手机浏览器访问 `http://<Mac的局域网IP>:8899`。

## 页面结构

| 路由 | 页面 | 说明 |
|---|---|---|
| `#/home` | 首页 | 场景入口 + 八县区网格 + 本周精选 |
| `#/map` | 特产地图 | 八县区全览 |
| `#/district/:id` | 县区页 | 该县区特产列表 + 产地介绍 |
| `#/product/:id` | 商品详情 | **「为什么可信」区块是核心差异化** |
| `#/gifts` | 礼盒与团购 | 三档礼盒 + 企业团购阶梯价 |
| `#/cart` | 已选清单 | — |
| `#/checkout` | 填写订单 | 收货信息 / 配送 / 支付（演示） |
| `#/orders` | 我的订单 | 下单后生成演示订单 |
| `#/me` | 我的 | 个人中心 |
| `#/about` | 关于这个原型 | **可直接拿给商会看的说明页**（含待确认问题清单） |

## 数据说明

- **县区与品类**：来自公开报道《阜阳各县区年货特产清单》
- **地理标志**：2025 年阜阳新增 7 个国家地理标志产品（公开报道）
- **非遗 / 名特优新**：市级、县级非遗名录、全国名特优新农产品名录
- **价格、规格、销量**：⚠️ **全部是演示数据，非真实报价**
- **商品图片**：暂无实拍图，用篆体字块 + 印章式色块代替，正式版需商会提供实拍

## 设计方向

- 暖米白宣纸底 + 墨绿主色 + 朱红印章式标签
- 标题用思源宋体（文化感），正文黑体（可读性）
- 不假装有商品照片——用排版和色块做视觉，比塞假图干净
- 八县区配色全部收敛到**暖土色域**（陶土红 / 橄榄绿 / 麦黄 / 苔绿 / 牛皮褐），去掉冷紫冷蓝
- 全屏**宣纸颗粒纹理**（SVG feTurbulence，`mix-blend-mode: multiply`），打破数字平面的无菌感

## 设计优化记录（2026-09-27 · taste-skill redesign 一轮）

按 redesign-skill 的 audit 清单逐项过了一遍，改掉的问题：

| 问题 | 处理 |
|---|---|
| 首页三列等宽卡片（最典型的 AI 布局） | 改成 **1 主 2 次非对称**：「自家吃」跨两行独占视觉重心 |
| 八县区配色冷暖混杂（紫/蓝/青跟暖色打架） | 8 个色全部收敛到暖土色域 |
| 卡片一律「边框+白底」，元素平铺无层次 | 去边框改**暖色阴影**（阴影带底色色相，不用纯黑）；商品 hero 底缘圆角 + 内容区负 margin 上浮 |
| 零纹理 | 加宣纸颗粒层 |
| 完全没有键盘焦点环 | 加 `:focus-visible`（可访问性硬伤） |
| 只有 `:active` 没有 `:hover` | 加全套 hover（包在 `@media(hover:hover)` 里，触屏不受影响） |
| 过渡时长不统一（160/180ms 混用）、按钮背景色是瞬变 | 统一 **220ms + 统一缓动曲线**，补上 background-color 过渡 |
| 表单只有 toast 提示 | 改**行内错误**：字段标红 + 错误文字 + 自动聚焦第一个错误字段 + 手机号格式校验 |
| 「为什么可信」用盾牌图标（audit 点名 cliché） | 换成凭证/证书图标 |
| 礼盒标签是药丸形 | 改方角 |
| 价格数字比例字体，列表里对不齐 | `font-variant-numeric: tabular-nums` |
| 标题孤字 | `text-wrap: balance` / `pretty` |
| 缺 favicon（控制台 404） | 内联 SVG 印章 favicon |
| 缺社交分享 meta | 补 description + og 标签（部署后发微信给商会老板，分享卡片才不难看） |
| 列表整体 mount 无动效 | 交错入场（逐项 40ms 延迟升起），并尊重 `prefers-reduced-motion` |
| 404 页太简陋 | 重新设计（大字 + 两个出口） |

### 追加修正：图块里的「孤字」问题

第一版图块用的是**地名/商品名的首字**（颍州区→「颍」、颍泉区→「泉」、方集馓子→「馓」），用户反馈"读起来难受"——这些字**不成词**，而大脑会自动尝试读它。

- **县区卡**：色块里改放**完整县区名**（颍州区 / 颍泉区 / 颍东区），名字不再在卡片主体重复；顺带发现颍东那抹麦黄配白字**对比度只有 3.05:1**（刚卡及格线），把色值加深到 `#A8781F`，现在 3.91:1
- **商品图块**：改用**2-3 字品类短名**（馓子 / 板鸭 / 芡实 / 椿酱），`short` 字段存在商品数据里
- **商品详情 hero**：放品类短名**大字**（2 字 84px / 3 字 64px）做视觉锚点，完整商品名留给下方标题——避免两处重复
- 全部 8 个县区色块的白字对比度实测在 **3.91 ~ 6.99** 之间，均满足大字 3:1 标准

## 已知限制 / 下一步

**这个原型的定位是「拿去和商会聊的实物」，不是成品。**

缺的：
- 真实商品图片
- 真实价格与供货信息
- 微信小程序版本（需转 WXML/WXSS）
- 真实支付（**个人主体小程序开不了微信支付与电商类目**）

上线前必须解决（见 `#/about` 页）：
1. 商会是否愿意组织销售？谁负责备货、发货？
2. 食品经营许可等资质是否齐全？食品责任由哪个主体承担？
3. 供货价、起订量、库存深度怎么定？
4. 商会企业是零售商还是团购/批发组织者？
5. 企业团购谁对接？定制腰封能否落地？
